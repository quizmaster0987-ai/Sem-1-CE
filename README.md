# Sem 1 CE Study Hub

A mobile-friendly, bilingual (English + Gujarati) study app for B.Tech Semester 1 Computer Engineering.

## Features
- Five subject areas: Mathematics, Physics (PEP), C Programming (LDP), CEP and UHV
- Chapter navigation, starter notes and sample MCQs
- Instant MCQ checking with explanations
- Written-answer practice with a basic keyword/rubric estimate
- Test mode, bookmarks and progress tracking
- Local device storage, install prompt, fullscreen and offline caching

## Run locally
Open `index.html` in a browser or serve this folder with any static web server.

## GitHub Pages
The workflow in `.github/workflows/pages.yml` publishes the repository root to GitHub Pages on pushes to `main`.

## Important content note
The repository was empty when development began. The included notes and questions are starter examples, not a complete or officially verified Silver Oak question bank. Add the official syllabus, question banks and notes to expand the content accurately. The written-answer checker is a basic local estimate, not an AI examiner or official marking scheme.

Progress is stored in the learner's browser using localStorage. It is not synced between devices.
